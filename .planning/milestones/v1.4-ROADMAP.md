## Overview

Capture and compare two task-planning regimes — **Arm A** (Claude-authored plan → 35B executes) vs **Arm B** (35B self-plans + executes) — across the three existing worked examples (F# FsLex/FsYacc calculator, Rust HTTP server, Scala 3 calculator) on the local Qwen **35B**, and publish the findings as a new **부록 D**. ## Milestone Summary

**Decimal Phases:** None.

**Key Decisions:**
- One OpenHands invocation per arm per example (single-session constraint); BOTH arms use the default CodeActAgent via the established headless CLI — no SDK PlanningAgent. Arm A embeds a numbered plan; Arm B gets the bare goal + "plan your own steps via the task tracker, then execute."
- Prompt symmetry enforced by a literal diff (`CONTROL-BLOCK SYMMETRY: PASS`) before any run — the only difference between arms is the planning input.
- n=3 per cell (median + min–max); `(단일 실행)` hedge reserved for single-run prose. All six cells reached n=3.
- Run order counterbalanced; arm-isolated gitignored workspaces; judged from JSONL, never the CLI exit code.
- Framing rule: "does an expert-authored plan help the 35B execute?" — NOT "Claude plans better." Mixed/inconclusive results are valid findings.

**The result (mixed/inconclusive — itself the finding):** an expert plan helps the 35B mainly when the task is **out-of-distribution** (F#: Arm A 1/3 PASS vs Arm B 0/3 — the one F# success came from the Claude plan navigating FsLex/FsYacc wiring); for **in-distribution** work the 35B self-plans just as well (Scala 3/3 vs 2/3+PARTIAL; Rust 3/3 tie, zero error-fix cycles). Extends the standing "distribution, not size" thesis onto the planning axis. P3 token metrics dropped (no `usage` in JSONL); timing carries a cache/run-order confound and is not a planning-quality signal.

**Issues Resolved During Milestone:**
- Phase-12 open unknowns resolved (TaskTracker emitted by 35B; no token usage in JSONL).
- Mid-Phase-13: the reused canonical-test detector mis-scored (heredoc first-match false-FAILs + null F# cells that would have blocked the gate). Fixed deterministically and re-ran all 18 captures (user-approved, `b7a74b9`); canonical now reproduces the JSONL-event-cited RUN-NOTES outcomes exactly.
