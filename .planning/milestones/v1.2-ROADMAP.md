## Milestone Summary

**Key Decisions:**
- [v1.2 scope]: minimal HTTP server (`GET / → "hello\n"`, no other routes) — keeps the milestone tight and gives the 35B a fighting chance on Rust ownership.
- [v1.2 dependencies]: **std only** (no hyper/axum/actix) — the agent does HTTP framing at the byte level; tutorial-grade visibility, no framework knowledge required of the model.
- [v1.2 model]: 35B only — tests the hypothesis that Rust is more in-distribution for 35B than FsLex was. Single-model run; 122B Rust comparison deferred (EXT-06).
- [v1.2 placement]: new 6부 structurally parallel to 4부 (calculator). Book = 1부~5부 + 6부 + 부록 A/B/C.
- [v1.2 honesty]: same discipline as v1/v1.1 — capture as-written, no manual fixes, disclose any scaffolding. The error-and-fix story is the chapter's material.
- [v1.2 phase structure]: 2 phases (8 + 9), same tight additive shape as v1.1; Phase 8 closes with a committed CAPTURE-MANIFEST.md capture gate before Phase 9 may begin.
