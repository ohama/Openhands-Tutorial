## Milestone Summary

**Key Decisions:**
- [v1.3 scope]: minimal Scala 3 integer calculator (`+ - * /`, precedence, parens), `scala-cli`, hand-rolled recursive descent, std-only (parallel to v1.2's std-only Rust). 7부 parallel to 4부/6부.
- [v1.3 model]: 35B only — tests whether Rust's v1.2 success generalizes to a second in-distribution language. Single-model run; 122B-on-Scala deferred (EXT-06).
- [v1.3 result]: hypothesis confirmed — capability is **domain-distribution, not model size**. The 35B that failed FsLex (OOD DSL) wrote Scala unaided (in-distribution).
- [v1.3 honesty / no ADT]: the agent did NOT use a `sealed trait Expr` ADT (the pre-run scope assumption); it wrote direct Int-returning recursive descent. The chapter honestly documents this rather than claiming the assumed design — caught at plan time, enforced through execution + verification.
- [v1.3 event-numbering]: the CAPTURE-MANIFEST (1-based JSONL positions) is authoritative for chapter citations; RUN-NOTES per-task scratchpad is 0-based — a convention note was added to RUN-NOTES to prevent the v1.2 TD-7/TD-8 drift (it did not recur).
