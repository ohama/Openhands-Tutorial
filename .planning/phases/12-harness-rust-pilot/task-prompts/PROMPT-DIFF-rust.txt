# Prompt Symmetry Diff — Rust Example (METH-01 Evidence)

## What was masked before diffing

1. **Workdir token**: Each prompt's arm-specific working directory path was replaced
   with the token `__WORKDIR__` so the path difference is not counted.
   - Arm A path masked: `/Users/ohama/projs/OpenHandsTests/oh-workdir-planning/arm-a/rust`
   - Arm B path masked: `/Users/ohama/projs/OpenHandsTests/oh-workdir-planning/arm-b/rust`

2. **Variable plan block removed**:
   - Arm A: everything from "Complete the following numbered steps in order, in
     this one session:" to the end of file was stripped.
   - Arm B: the single line "Plan your own implementation steps using the task
     tracker, then execute each step. Do not ask for confirmation between steps."
     (and trailing content) was stripped.
